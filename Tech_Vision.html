Pesquisa & Validação

Fundamentado em dados, validado por usuários

Metodologia ágil, testes funcionais e validação com o System Usability Scale — referência mundial em UX.

🔬 Problema de Pesquisa

Como uma aplicação mobile baseada em marketplace pode ampliar o alcance de vendas de pequenas óticas e proporcionar uma experiência segura e eficiente para a compra de óculos online?

📚 Embasamento Científico

Baseado em marketplaces digitais para PMEs (Marzi et al., 2023), OCR em receitas médicas (Soeno et al., 2024; Ponnuru, 2024) e validação de usabilidade (Nielsen, 2000).

Spring Boot → · PostgreSQL → · Firebase →

⚙️ Metodologia Ágil

Scrum com entregas incrementais, prototipação no Figma, Android Studio + Java, backend Spring Boot, banco PostgreSQL, IA Python para leitura de receitas e infraestrutura AWS.
